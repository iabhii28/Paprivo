## Overview

**Paprivo** is an open-source Android application designed to make everyday
PDF tasks simple, fast, and accessible.

It brings useful PDF creation, management, and editing features together
in one clean and minimal Android application.

### Highlights

- Clean and minimal Android UI
- Native Android experience
- Black and White themes
- Fast PDF operations
- Simple file management
- Local document processing
- Open source

---

## Features

### PDF Tools

| Feature | Description |
| --- | --- |
| **Merge PDF** | Combine multiple PDF files into one document. |
| **Split PDF** | Split PDFs into separate documents or page ranges. |
| **Compress PDF** | Reduce PDF file size. |
| **Extract Pages** | Extract selected pages from a PDF. |
| **Delete Pages** | Remove unwanted pages. |
| **Reorder Pages** | Rearrange PDF pages. |
| **Rotate PDF** | Rotate PDF pages. |
| **PDF Viewer** | View PDF documents inside the application. |
| **PDF to Images** | Convert PDF pages into image files. |

### Create PDF

Create PDF documents from supported files and sources.

Supported image formats include:

- JPG
- JPEG
- PNG
- WEBP
- HEIC
- HEIF

Depending on the tool, Paprivo supports options such as:

- Multiple images
- Image ordering
- Page size
- Page orientation
- Margins
- Image quality
- Image rotation
